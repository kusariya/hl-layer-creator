# SVGMap 公式チュートリアルの使い方

参照元: [SVGMap Tutorials](https://svgmap.github.io/tutorials/)

このチュートリアルは、SVGMapコンテンツを作る開発者向けに、基本から応用へ進む教材である。チュートリアルのディレクトリを一式コピーして動作させる構成も案内されている。AIエージェントは、要件に対応する段階と関連ファイルを選び、例を実装の出発点として確認する。

## チュートリアルの区分

| 区分 | 主な内容 | 適用する作業 |
| --- | --- | --- |
| Part 1: Basics（Tutorial 1–4） | SVGMapの基本表示、POI、レイヤー分割、静的タイル、ビットマップ画像地図 | 初期表示、Container.svg、静的SVG、座標配置、既存データの重ね合わせ |
| Part 2: WebApp Layer Edition（Tutorial 5–11） | タイルピラミッド、GeoJSON、ベクトルタイル、メッシュ、メッシュタイル、カスタムダイアログ、メッシュのビットマップ化、地図を使った位置指定UI | LaWAでデータ取得・描画・UIを実装する作業 |
| Part 3: Web Service Integration | Webサービスとの連携 | WMS/WFS等のサービス連携が必要な作業 |
| Part 4: Utilizing Existing WebApp Layers | 既存WebApp Layerの活用 | 既存レイヤーを組み合わせる、または再利用する作業 |

チュートリアルサイトの目次・個別ページを開き、現在の内容とファイル構成を確認する。番号や章立てだけから細部の挙動を推測しない。

## 進め方

1. まずユーザーの成果物とデータ形態を確かめ、Tutorial 1–4、5–11、Part 3、Part 4のいずれが近いか選ぶ。チュートリアルを最初から順にすべて実行する必要はない。
2. 個別チュートリアルで、必要なSVG/HTML/JavaScript、依存ファイル、Container.svgの参照関係を確認する。動作例のプロジェクト構造が重要な場合は、必要なファイル群を揃えて扱う。
3. 例から適用する要素と、ユーザー要件に合わせて変更する要素を分ける。API名、属性、ライブラリ版など時間で変わりうる情報は、現行の公式ドキュメントや `svgmapjs` の実装でも確認する。
4. ライセンス、出典、クロスオリジン制約、データの更新性など、チュートリアルの目的外となる条件は別途確認する。チュートリアルのサンプルを、データ保存・再配布や利用許諾の根拠として扱わない。
5. 採用した構成と参照したチュートリアルを、設計・実装の説明に短く記録する。

## 読み分けの目安

- 固定図形や既に用意されたSVGを表示する: Part 1から静的レイヤー、Container.svg、レイヤー化の例を参照する。
- タイルや属性データを動的に扱う: Part 2から対象データ型に近いチュートリアルを選ぶ。
- サーバーの地図サービスを使う: Part 3の関連ページを確認し、サービス側の仕様・利用条件も調べる。
- 既に公開されたWebApp Layerを組み込む: Part 4で参照方法と前提条件を確認する。
- 開発せず手元データをSVGMapとして使いたい: チュートリアル導入ページが案内するツール向け手順を優先し、アプリ開発向け手順と混同しない。

## チュートリアルの位置づけ

チュートリアルは具体的な教材・実装例であり、HLA全体の規範や最新APIリファレンスを置き換えない。例に含まれる古いファイル名、リビジョン、表記ゆれは、現行の公式コードと照合して判断する。また、特定の設計原則（例: リモートfetch優先）を全データに一律適用する根拠にしない。
